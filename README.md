


########################################### Read Me ##################################################################
This project is created using 3 languages. The main ones used are HTML and CSS, but there is also some JavaScript. 
The focus of the project was to create a website for a gallery. This includes the NAV-bar, hero section and a 
section for the workshop presentation/product cards. There is also a functioning order menu created using 
HTML and CSS. The logic behind the popup is using JavaScript for its functions.
